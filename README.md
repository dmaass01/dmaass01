### 🛠️ What I'm building

**Caselink** — an AI-native visa & immigration platform for universities and HR teams. I'm the sole engineer behind:

- A multi-agent layer on **Python + LangGraph** — tool-using agents with human-in-the-loop review on every client-facing output
- **Automated credential recognition**: reverse-engineered the public Anabin database (German study-certificate registry) into a usable API, with a custom matching algorithm and a nightly full-dataset sync
- An **eval harness** (offline scoring + LLM-as-judge) that turns production corrections into regression tests
- **RAG with Voyage AI re-ranking** for retrieval precision
- A polyglot architecture: a TypeScript/Next.js app and a dedicated Python agents service over event-scoped internal APIs
- Production integrations & runtime: DocuSeal (digital signing), Gmail / Google Cloud (email automation), FastAPI on Fly.io, Postgres, LangSmith tracing
